# SR_deac
Repository pentru activitatea lui Deac Maximilian in cadrul disciplinei Sisteme de recomandare


=== Lab 2 === 

Dataset-ul ales contine informatii despre aproximativ 2.2k laptop-uri. 
Informatiile continute in dataset sunt urmatoarele:
- Nume complet laptop (string/in tabel se regaseste ca Laptop)
- Status (string)
- Brand (string)
- Model (string)
- CPU (string)
- RAM (int)
- Storage (int)
- GPU (string)
- Screen (double/valori reprezentate in inches)
- Touch (string)
- Final Price (double)

=== Lab 3 ===

Datasetul este incarcat in Recombee prin recombee_items. 

Categoriile din dataset incluse sunt Numele laptopului (Laptop), model procesor (CPU), model GPU (GPU sau daca nu e in dataset, il consideram Integrated), capacitate RAM (RAM) si stocare (Storage).
